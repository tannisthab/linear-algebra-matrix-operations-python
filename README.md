# Linear Algebra Matrix Operations Using Python

## Overview
This project implements fundamental linear algebra operations using Python, NumPy, and SymPy as part of the Mathematical Foundation for Data Science I curriculum.

## Objectives
- Perform fundamental matrix operations.
- Calculate determinants, inverses, and matrix decompositions.
- Solve systems of linear equations using Gaussian elimination.
- Compute eigenvalues and eigenvectors.
- Validate numerical and symbolic results.

## Technologies Used
- Python
- NumPy
- SymPy
- Jupyter Notebook

## Implementation
The project includes:
1. Matrix creation and basic operations.
2. Determinants and inverse calculations.
3. QR, LU, and Singular Value Decomposition.
4. Gaussian elimination and linear equation solving.
5. Eigenvalue and eigenvector computation.
6. Numerical and symbolic validation.

## Project Structure
- `Linear_Algebra_Notebook.ipynb` – Fully documented implementation with execution outputs.
- `Screenshots/` – Evidence of program execution and results.

## Learning Outcomes
Developed practical understanding of computational linear algebra and its applications in data science, machine learning, and artificial intelligence.
